# 与课程大纲的对应关系

大纲共 32 课时。这套代码只做**仿真部分**。下表说明每一课时能用哪一节，还缺什么。

- ✅ 仿真部分已完成，可以直接上课
- 🟡 仿真部分已完成，另一部分需要真机或补充内容
- 🔧 只能用真机
- ⬜ 还没做

## 建议的补充顺序

1. **真机对齐**（约 1 天，需要真机）：关节方向和零位、相机内参，这样仿真里训练的模型才能迁移到真机。直接支持第 3、5、8、12、25 课。
2. **多任务数据**（纯软件，约 1 天）：在第 05 节里加「抓绿色 / 蓝色方块」和对应的语言指令，重新训练 GR00T。第 13 课「听懂话」才有说服力。
3. **Isaac Lab + Mimic**（纯软件，2–3 天）：支持第 15、20、21、24 课，也是大纲的数据主线。
4. **Cosmos Transfer**（需要 40 GB 以上显存）：支持第 15、26 课。
