# 04 逆运动学：算出抓取姿态

对应大纲：第 18 课「机器人数学」（旋转矩阵、正 / 逆运动学、关节空间和末端空间）。

## 目标

- 正运动学：给定关节角，算出夹爪在哪里、朝哪边。
- 逆运动学：给定「夹爪要到哪里、朝哪边」，反过来算关节角。
- 理解「抓取点」：夹爪上真正接触物体的位置，不是 link 的原点。

## 运行

```bash
tools/run_isaac.sh lessons/04_ik_grasp/grasp_ik.py    # 约 1 分钟 → outputs/grasp/grasp.json、images/grid.png
```

## 你会看到

- 两只手臂的逆运动学都在十几次迭代内收敛，位置误差约 2 mm。
- 抓取过程：靠近 → 下探 → 夹紧 → 升降上抬 12 cm。两个方块都升高约 10.7 cm（`grasp.json`），`images/grid.png` 是这四步的画面。

## 讲解要点

- **任务是 6 维的**：抓取点的位置（3 维），手指朝下（2 维），夹爪闭合方向和方块边平行（1 维）。这正好用掉机械臂 6 个关节的自由度。
- **数值雅可比**：让每个关节转一个很小的角度，看夹爪动了多少，就得到雅可比矩阵的一列。再用阻尼最小二乘法一步步逼近目标。Isaac Sim 自带的雅可比在这个模型上行列顺序不对，所以这里用数值差分（`common/alohamini_ik.py`）。
- **抓取点**：AlohaMini2 的夹爪是一根固定指加一根转动指。方块要贴着固定指的内侧面，所以抓取点在固定指内侧面外 2 cm 处。
- **调试过程本身就是好教材**：
  - 一开始把 link 原点对准方块，手指压在方块顶上。
  - 夹爪闭合方向和方块边差 10°，方块的角会顶住手指。
  - 每一次失败都能从画面和数字里找到原因。

## 课堂练习

1. 把 `common/alohamini_ik.py` 里 `GRASP_POINT` 的 x 从 0.017 改成 0.007，重新运行，看手指落在哪里、能不能抓起来。
2. 修改 `common/alohamini_scene.py` 里 `CUBES` 左方块的 y，从 −0.40 逐步改到 −0.45，找出左臂够不到的边界。
3. 进阶：在 `grasp_ik.py` 里打印每次迭代的误差，画出收敛曲线。

## 文件

- `grasp_ik.py`：规划并执行双臂抓取，统计方块升高了多少。
- 逆运动学代码在 `common/alohamini_ik.py`：`ArmIK` 解单臂，`plan_bimanual_pick` 规划双臂。
